This program currently requires MATLAB by The Mathworks
(version 6.0 or higher) in order to run.

http://www.mathworks.com/products/matlab/

To Install:

   Unzip the distribution file into any subdirectory. This
   will be the directory from which MATLAB runs JBike6.

To Run (From MATLAB):

   Make the directory into which you installed JBike6
   the current directory.

   Now you can run JBike6 by typing 'JBike6' at the
   MATLAB command prompt

   >JBike6
   
   and then pressing the enter key.
