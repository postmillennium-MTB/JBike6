Reference — Applying Control Theory to Bicycle Linearized Equations of Motion: Adapted from Andrew Dressel & Prof. Andy Ruina (Cornell Biorobotics & Locomotion Lab, 2003–2015). Notice how positive steer torque (τδ > 0, turning handlebars right) initially causes a brief negative roll (φ < 0, leaning left) due to the right-half-plane non-minimum-phase zero of Gφτ(s) before the bike carves right—the exact physics of countersteering. 
% MATLAB Control System Toolbox Equivalent (Dressel & Ruina):
M = inv(M0);  S = M*(C1.*v);  K = M*(g*K0 + K2.*v^2);
A = [0, 1, 0, 0; -K(1,1), -S(1,1), -K(1,2), -S(1,2); 0, 0, 0, 1; -K(2,1), -S(2,1), -K(2,2), -S(2,2)];
B = [0; M(1,2); 0; M(2,2)];   C = [1, 0, 0, 0];   D = 0;
[numG, denG] = ss2tf(A, B, C, D);   G = tf(numG, denG);   pzmap(G);
